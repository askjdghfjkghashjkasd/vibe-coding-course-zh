## 0.引言：编程语言的作用

想象你需要与一个只懂二进制的机器人通信：

- **直接输入0和1**——最原始，极其低效;一个错误的0或1，一切就坏了（机器语言）
- **使用助记符代替** — `MOV AX, 1`比`10110000 00000001`（汇编语言）更容易识别
- **使用近自然语言** — `int sum = 1 + 2;` 人类可以直接阅读（高级语言）

**编程语言是人机交流的桥梁**，经过70多年的发展，朝着“更接近人类思维”的方向发展。

## 2.编程范式：问题思考方式

编程范式不是语言特征，而是**思维方式**——就像写作有不同的体裁，比如诗歌、小说和散文。

### 2.1 命令式编程：逐步执行描述

```c
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += arr[i];
}
```

### 2.2 面向对象编程：数据和行为的封装

```python
class Dog:
    def __init__(self, name):
        self.name = name
    def bark(self):
        print(f"{self.name} says woof!")
```

### 2.3 函数式编程：纯函数与不可变状态

```haskell
sum = foldl (+) 0
-- Same input always produces the same output
```

### 2.4 声明式编程：描述目标而非步骤

```sql
SELECT name FROM users WHERE active = true
-- The database decides the most efficient way to query
```

::: 提示 实际操作
大多数现代语言都是**多范式**。Python支持面向对象和函数式编程;JavaScript也是如此。不要纠结于“哪种范式最好”——选择最适合问题的方法。
:::

## 3.类型系统基础

| |强类型 |弱类型 |
|---|---|---|
|**静态音**Java、Rust、TypeScript——最安全 |C、C ——高效但需谨慎 |
|**动态** |Python、Ruby — 灵活且安全 |JavaScript、PHP — 灵活但易出错 |

**关键问题**：`"1" + 1`代表什么？
- **JavaScript（弱类型）**： `"11"` — 为你默默转换
- **Python（强烈类型）**： `TypeError` — 强制你清晰思考

## 4.编译 vs 解释型

| |编译 |解释 |JIT |
|---|---|---|---|
|**进程**先翻译所有内容，然后运行 |逐行读取并执行 |先解释，热点再编译 |
|**速度**最快 |慢 |中等 |
|**调试**需要编译等待 |即时反馈 |即时优化 |
|**代表** |C，Rust，Go |Python，Ruby |Java，JavaScript |

## 5.编程语言选择

### 按剧本选择

|剧本 |推荐语言 |原因 |
|---|---|---|
|**网页前端** |JavaScript，TypeScript |浏览器只理解 JS |
|**Web后端** |Go、Java、Python、Node.js |成熟生态系统 |
|**移动开发**Swift（iOS），Kotlin（Android）|官方推荐 |
|**AI / 数据** |Python |PyTorch、Pandas都用Python语言 |
|**系统编程**C，Rust |直接硬件控制 |
|**云原生** |Go Rust |Docker/K8s 是用 Go 编写的 |

### 学习路径推荐

1. **Python** — 最简单的语法，AI时代的入门点
2. **JavaScript** — 网页开发必备，涵盖前端和后端
3. **TypeScript** — 为 JS 添加类型系统，体验静态类型
4. **Go or Rust** — 理解编译语言和底层概念

## 6.摘要

::: 提示 要点
1. **语言进化**：从机器语言到高级语言，越来越接近人类思维
2. **编程范式**：命令式、面向对象、函数式、声明式——每种都有适用场景
3. **类型系统**：静态/动态，强/弱——影响安全性和灵活性
4. **执行模型**：编译快速，解释灵活，JIT 结合两者
5. **没有万能灵丹**：根据情景选择语言，而不是追求“最佳语言”
:::
