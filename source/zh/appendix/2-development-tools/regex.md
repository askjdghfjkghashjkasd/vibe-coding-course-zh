# 正则表达式基础

> 💡 **学习指南**：正则表达式看起来像胡言乱语？它们其实只是一个迷你“描述文本模式的语言”。本章带你从零开始理解正则表达式的核心思想，并教你用几个关键符号解决80%的文本搜索和验证问题。

---

## 0.需要正则表达式的动机

想象以下情景：
- 在大型日志文件中查找所有IP地址
- 验证用户的电子邮件格式是否正确
- 替换文本中所有日期格式，从`2024/01/15`@到`2024-01-15`
- 从网页源代码中提取所有链接

**用纯字符串搜索吗？** 你需要大量的 `if-else` 逻辑。
**用正则表达式？** 一个模式就能完成。

## 2.核心概念：你结合的构建模块

正则表达式的本质是结合**三种类型的构建模块**来创建你想要的模式：

### 2.1 第一块：角色职业（匹配角色）

|语法 |含义 |示例 |
|---|---|---|
|`.` |任何角色 |`a.c` → abc，a1c，a c |
|`\d` |数字 [0-9] |`\d\d` → 42,99 |
|`\w` |字母/数字/下划线 |`\w+` →你好，user_1 |
|`\s` |空白字符 |匹配空格、制表符 |
|`[abc]` |集合中的任意一个 |`[aeiou]` →元音 |
|`[^abc]` |不在集合中 |`[^0-9]` →非数字字符 |

### 2.2 第二块：量词（匹配次数）

|语法 |含义 |示例 |
|---|---|---|
|`*` |0次或以上 |`ab*` → A、AB、ABB |
|`+` |1次或更多 |`ab+` → AB，ABB（不匹配A） |
|`?` |0次或1次 |`colou?r` →颜色，颜色 |
|`{3}` |正好三次 |`\d{3}` → 123 |
|`{2,4}` |2到4次 |`\d{2,4}` → 12,1234 |

### 2.3 第三块：位置与分组

|语法 |含义 |示例 |
|---|---|---|
|`^` |行首 |`^Hello` →行以“你好”开头 |
|`$` |行尾 |`end$` →行以结尾 |
|`\b` |单词边界 |`\bcat\b` → 猫（与捕获不匹配） |
|`(...)` |捕获组 |`(\d+)-(\d+)` →单独捕获 |
|`a\|b` |或者 |`cat\|dog` →猫或狗 |

## 3.实践：常见验证模式

### 3.1 电子邮件验证

```
[\w.+-]+@[\w-]+\.[\w.]+
```

细分：
- `[\w.+-]+` — 用户名部分（字母、数字、点、加号、连字符）
- `@` — 字面意义的 @
- `[\w-]+` — 域名部分
- `\.` — 转义点
- `[\w.]+` — 顶级域名

### 3.2 中国电话号码验证

```
1[3-9]\d{9}
```

分解：
- `1` — 以 1 开头
- `[3-9]` — 第二位数字是 3-9
- `\d{9}` — 后跟 9 个数字

### 3.3 密码强度检查

```
^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$
```

解析：
- `(?=.*[a-z])` — 至少一个小写字母（前瞻断言）
- `(?=.*[A-Z])` — 至少一个大写字母
- `(?=.*\d)` — 至少一个数字
- `.{8,}` — 总长度至少为8个字符

## 4. 在代码中使用正则表达式

### JavaScript

```javascript
const text = 'Contact: 13812345678 or 15099887766'
const regex = /1[3-9]\d{9}/g
const phones = text.match(regex)
// ['13812345678', '15099887766']

// Replace
text.replace(/\d{4}(?=\d{4}$)/, '****')
// Hide the middle four digits of the phone number

// Validate
/^[\w.+-]+@[\w-]+\.[\w.]+$/.test('user@example.com')
// true
```

### Python

```python
import re

text = 'Price is 99 yuan, discount 20 yuan'
numbers = re.findall(r'\d+', text)
# ['99', '20']

# Replace
re.sub(r'\d+', 'X', text)
# 'Price is X yuan, discount X yuan'

# Group capture
match = re.search(r'(\d+)-(\d+)', '2024-01-15')
match.group(1)  # '2024'
match.group(2)  # '01'
```

## 5. 贪婪与懒惰：一个关键区别

```
Text: <b>hello</b> and <b>world</b>
```

| 模式 | 匹配结果 | 解释 |
|---|---|---|
| `<b>.*</b>` | `<b>hello</b> and <b>world</b>` | 贪婪：尽可能多地匹配 |
| `<b>.*?</b>` | `<b>hello</b>` | 懒惰：尽可能少地匹配 |

::: tip 💡 提示
默认是贪婪模式。在量词后加上 `?` 可切换到懒惰模式。大多数情况下，你会想使用懒惰模式。
:::

## 6. 总结

::: tip 📚 关键要点
1. **正则表达式 = 描述文本模式的小型语言**，用于搜索、匹配和替换
2. **三种构建模块**：字符类（匹配什么）、量词（匹配多少次）、位置/分组
3. **\d \w \s** 是最常用的三种字符类，分别表示数字、单词字符和空白符
4. **无需从零编写**：常见场景已有成熟的正则模式可重复使用
5. **贪婪 vs. 懒惰**：默认是贪婪（匹配更多），加上 `?` 可切换为懒惰（匹配更少）
:::
