## 0.大局观：搜索本质概述

搜索的本质是一个**信息检索**问题：给定一个查询，从大量文档中找出最相关的结果，并按相关性排序返回。

该过程分为两个阶段：

- **索引阶段（离线）**：预处理所有文档并构建高效的查找结构
- **查询阶段（在线）**：用户输入关键词时，快速找到匹配文档并进行排名

::: 提示 为什么不使用类似数据库的查询？
`SELECT * FROM products WHERE name LIKE '%red dress%'`看似可用于搜索，但需要**完整表扫描**——逐行检查。当数据达到数百万条记录时，该查询变得极其缓慢。反向索引将O（n）操作转换为O（1）查找。
:::

## 1.倒挂索引：搜索引擎的“核心”

传统数据库使用**前向索引**：从文档ID到文档内容。搜索引擎使用**倒置索引**：从关键词到包含它们的文档列表。

<InvertedIndexDemo />

|索引类型 |方向 |查找方法 |用例 |
|---------|------|---------|---------|
|前向索引 |文档→内容 |知道 ID，查找内容 |数据库主键查询 |
|反扣索引 |关键词→文档列表 |知道关键词，查找文档 |全文搜索 |

::: 提示 倒挂索引构建过程
1. **文档收集**：收集所有需要可搜索的文件
2. **代币化**：将文档拆分为单独的术语
3. **构建映射**：记录每个术语出现在哪些文档中（包括位置、频率等）
4. **持久存储**：将索引写入磁盘以便快速查找
:::

## 2.分词与文本分析

令牌化是搜索引擎的第一步，也是中文搜索面临的最大挑战。英语自然用空格分隔词，但中文没有分隔符——“乒乓球拍卖了”可以分为“乒乓球/拍卖/了”或“乒乓/球拍/卖/了”。

|分词方法 |描述 |示例 |
|---------|------|------|
|标准分词器 |按空格和标点分割（英文） |“你好，世界” → [“你好”，“世界”] |
|中文分词器 |基于词典或模型的细分 |"搜索引擎" → ["搜索", "引擎"] |
|N-gram |固定长度滑动窗口 |"搜索" → ["搜索", "索引"] |
|自定义词典 |添加商业专用术语 |“iPhone16ProMax”作为单一词汇 |

::: 提示 文本分析流程
分词只是文本分析中的一步。完整的流程包括：
1. **字符过滤**：去除HTML标签和特殊字符
2. **分词化**：将文本拆分为令牌
3. **停止词过滤**：去除无意义的高频词，如“的”、“了”、“是”
4. **同义词扩展**：将“手机”（手机）扩展为“手机、电话、移动电话”
5. **词干**：将“running”简化为“run”（英语）
:::

## 3.相关性排名：最“相关性”的概览

找到匹配的文件只是第一步;更重要的是，**排名**——将最相关的结果排在最前面。

|算法 |原理 |特征 |
|------|------|------|
|TF-IDF |条款频率（TF） × 反向文档频率（IDF） |经典算法，简单有效 |
|BM25 |TF-IDF的改进版，增加了文档长度归一化 |Elasticsearch的默认算法 |
|向量搜索 |将文档和查询转换为向量，计算余弦相似度 |支持语义搜索 |

::: 提示 TF-IDF 直观理解
- **TF（术语频率）**：术语在文档中出现次数越多，该文档与该术语相关的可能性越大
- **IDF（反向文档频率）**：术语出现在文档的数量越少，其判别力越强
- “的”出现在所有文档中（低IDF），因此搜索“的”毫无意义
- “Elasticsearch”只出现在少数文档中（高IDF），因此搜索它能精确定位相关内容
:::

## 4.Elasticsearch：最受欢迎的搜索引擎

Elasticsearch 目前是最受欢迎的开源搜索引擎，基于 Apache Lucene，提供分布式、基于 RESTful API 的全文搜索功能。

|概念 |描述 |
|------|------|
|索引 |类似于数据库“表”，存储同类型的文档 |
|文档 |单条记录，JSON格式 |
|分片 |一个分区，将索引分割到多个节点 |
|副本 |一份副本，提供高可用性和读取缩放 |
|映射 |字段类型定义，类似于数据库模式 |
|分析器 |文本分析器，定义分词规则 |

::: 提示 ES 与数据库
Elasticsearch 并非旨在取代数据库;它作为搜索层与数据库并行工作。典型架构是：数据写入数据库→同步到 ES →搜索请求发送到 ES →详细信息请求发送到数据库。
:::

## 5.搜索优化：让搜索“更智能”

|优化方法 |描述 |效果 |
|---------|------|------|
|同义词 |搜索“手机”（手机）还能找到“电话”（电话） |提高记忆力 |
|拼写修正 |“iphoen” 自动更正为“iphone” |容错 |
|自动补全 |输入“苹”暗示“苹果手机”（苹果手机） |更好的用户体验 |
|高亮 |搜索结果中红色显示的匹配词 |视觉清晰度 |
|权重调整 |冠军赛权重>内容 比赛权重 |提升精度 |
|筛选与聚合 |按价格区间、品牌筛选 |范围较窄的结果 |

## 摘要

搜索引擎是互联网应用的核心基础设施。理解倒排索引、分词和相关性排序——这三个核心概念——就意味着你已经掌握了搜索引擎的精髓。

本章要点：

1. **倒排索引**：从关键词到文档的反向映射是搜索引擎的核心数据结构
2. **分词是基础**：中文分词是搜索质量的关键；选择合适的分词器至关重要
3. **BM25排序**：基于词频和文档频率的相关性评分是ES的默认算法
4. **ES架构**：分片和副本实现分布式处理和高可用性
5. **搜索优化**：同义词、拼写纠正和自动补全让搜索更智能
