## 1. 从神经元到网络

### 单个神经元

神经网络中最小的单位是**神经元**。它模仿生物神经元的工作方式：接收多个输入信号、计算加权和，并通过激活函数产生输出。

```
Input x1 ──→ ×w1 ──┐
Input x2 ──→ ×w2 ──┼──→ Σ(weighted sum) + b(bias) ──→ f(activation function) ──→ Output
Input x3 ──→ ×w3 ──┘
```

数学表达式: **y = f(w₁x₁   w₂x₂   w₃x₃   b)**

<NeuronDemo />

### 激活函数：非线性的重要性

如果没有激活函数，无论你堆叠多少层神经元，结果总是等同于一次线性变换（矩阵乘法）。激活函数引入了**非线性**，使网络能够学习复杂模式。

| 激活函数 | 公式 | 特点 | 常见用途 |
|---------|------|------|---------|
| ReLU | max(0, x) | 简单、高效、训练快速 | 隐藏层默认选择 |
| Sigmoid | 1/(1 e⁻ˣ) | 输出范围 0~1 | 二分类输出层 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ e⁻ˣ) | 输出范围 -1~1 | RNN中常用 |
| Softmax | eˣᵢ/Σeˣⱼ | 输出为概率分布 | 多分类输出层 |

### 从神经元到网络

将多个神经元组织成**层**，并顺序连接多层以形成神经网络：

```
Input Layer      Hidden Layer 1        Hidden Layer 2        Output Layer
(features)       (extracts low-level   (extracts high-level   (prediction)
                  features)             features)

 x1 ──→  [○ ○ ○ ○] ──→ [○ ○ ○] ──→  [○ ○]
 x2 ──→  [○ ○ ○ ○] ──→ [○ ○ ○] ──→  Cat/Dog
 x3 ──→  [○ ○ ○ ○] ──→ [○ ○ ○]
```

| 概念 | 描述 |
|------|------|
| 输入层 | 接收原始数据（图像像素、文本向量等） |
| 隐藏层 | 中间处理层；层数越多意味着网络越“深”（即深度学习中的“深”） |
| 输出层 | 生成最终预测（分类概率、回归值等） |
| 前向传播 | 数据从输入层逐层流向输出层的过程 |

::: tip 为什么叫“深度”学习？
传统的机器学习通常只使用1–2层。当隐藏层数量增加到几十甚至上百层时，就称为“深度”学习。更深的网络可以学习更抽象的特征：第一层学习边缘，第二层学习纹理，第三层学习部件，更深的层则学习“这是猫”。
:::

## 2. 网络如何学习

神经网络中的“学习”本质上是一个**优化问题**：寻找一组权重 (w) 和偏置 (b)，使网络的预测尽可能接近正确答案。

### 三步训练循环

```
1. Forward propagation: Feed input data, get predictions
2. Compute loss: Use a loss function to measure the gap between predictions and true values
3. Backpropagation: Calculate the gradient of each weight based on the loss, then update weights
   ↓
Repeat the above steps until the loss is sufficiently small
```

### 损失函数：衡量“你有多错”

损失函数量化了预测值与真实值之间的差距。训练的目标是最小化损失。

| 损失函数 | 公式概述 | 使用场景 |
|---------|---------|---------|
| MSE（均方误差） | 预测值与真实值差的平方的平均值 | 回归问题 |
| 交叉熵 | -Σ y·log(ŷ) | 分类问题 |
| 二元交叉熵 | 交叉熵的二元版本 | 二分类问题 |

### 梯度下降：寻找最低点

想象你站在一座山上，蒙着眼睛，需要走到最低点。你能做的只是**感受脚下的坡度，然后沿着下坡方向走一步**。这就是梯度下降。

```
Loss
  ↑
  │    ╱╲
  │   ╱  ╲      ← Current position
  │  ╱    ╲    ↙ Descend along gradient direction
  │ ╱      ╲╱   ← Local minimum
  │╱            ╲╱  ← Global minimum
  └──────────────→ Weight value
```

| 概念 | 描述 |
|------|------|
| 梯度 | 损失函数关于每个权重的偏导数，表示“为减少损失应该调整的方向” |
| 学习率 | 每次更新的步长。步长太大可能会错过最小值；步长太小则收敛太慢 |
| 批量大小 | 每次计算梯度时使用的样本数。全量批次太慢，单样本太噪声化，迷你批次是折中选择 |

### 反向传播：链式法则的胜利

反向传播是一种高效的梯度计算算法。它利用微积分中的**链式法则**，从输出层开始，逐层向后计算每个权重对损失的贡献。

```
Forward propagation: Input → Hidden Layer 1 → Hidden Layer 2 → Output → Loss
Backpropagation:    Loss → Output → Hidden Layer 2 → Hidden Layer 1 → Update all weights
```

::: 提示 反向传播的直觉
把神经网络想象成一个装配线。当产品（预测）出现问题（损失大）时，你需要从最后一步回溯，检查每一步（每层的权重）对问题的贡献，然后按比例调整。贡献多的调整多；贡献少的调整少。
:::

## 3. 主流网络架构

不同类型的数据需要不同的网络架构。选择正确的架构可以事半功倍。

<NetworkLayersDemo />

### 3.1 CNN（卷积神经网络）

CNN 是图像处理的王者。核心思想：在图像上滑动小卷积核以提取局部特征。

```
Input image → [Convolution → Activation → Pooling] × N → Fully Connected Layer → Output
  28×28      Extract edges/textures/shapes                   Classification result
```

| 特性 | 描述 |
|------|------|
| 局部连接 | 每个神经元只查看一个小的区域，而不是整个图像 |
| 参数共享 | 相同的卷积核在整个图像上重复使用，大大减少了参数数量 |
| 平移不变性 | 图像左侧或右侧的猫仍然可以被识别 |
| 分层特征 | 浅层学习边缘，深层学习语义 |

代表模型：LeNet, AlexNet, VGG, ResNet, EfficientNet

### 3.2 RNN（循环神经网络）

RNN 设计用于**序列数据**。它的隐藏状态会传递到下一个时间步，为网络提供一种“记忆”功能。

```
Time step t1    Time step t2    Time step t3
  "I"   ──→    "like"  ──→    "cats"
   ↓             ↓             ↓
  [h1]  ──→    [h2]   ──→    [h3] ──→ Output
   ↑             ↑             ↑
 Hidden state passes between time steps (memory)
```

| 变体 | 解决的问题 | 核心机制 |
|------|-----------|---------|
| 普通 RNN | 基本序列建模 | 简单的循环连接 |
| LSTM | 长序列中的梯度消失问题 | 忘记门、输入门、输出门 |
| GRU | LSTM 参数过多 | 简化为重置门和更新门 |
| 双向 RNN | 只能看到过去 | 同时进行正向和反向处理 |

::: tip LSTM 的门控机制
LSTM 的优雅之处在于它的三个“门”：**忘记门**决定丢弃哪些旧记忆，**输入门**决定存储哪些新信息，**输出门**决定输出什么。这就像阅读一本书——你有选择地记住重要情节，忘记无关细节。
:::

### 3.3 Transformer：注意力就是一切

2017 年，谷歌发表论文《Attention Is All You Need》，提出了 Transformer，从根本上改变了人工智能领域。它用**自注意力机制**取代了循环结构，并成为 GPT、BERT 和 Claude 等大型模型的基础。

```
Input sequence → Embedding + Positional Encoding → [Multi-Head Attention → Feed-Forward Network] × N → Output
                                                           ↑
                                          Every token can "see" every other token
```

| 优势 | 描述 |
|------|------|
| 并行计算 | 与必须顺序处理的 RNN 不同，Transformer 可以并行处理整个序列 |
| 长距离依赖 | 任意两个位置之间的直接连接，无论距离远近 |
| 可扩展性 | 模型越大、数据越多，性能越好（扩展法则） |

**自注意力的直觉**：在阅读句子“The cat sat on the mat because **it** was tired”时，“it”需要关注“cat”才能理解意思。自注意力让模型学习这种关联——为序列中每对 token 计算“相关性分数”。

## 4. 训练的艺术

拥有良好的架构还不够——训练过程中有许多陷阱需要避免。

### 4.1 过拟合与欠拟合

| 问题 | 表现 | 原因 | 解决方法 |
|------|------|------|---------|
| 过拟合 | 在训练集上表现良好，但在测试集上表现差 | 模型过于复杂，“记住答案”而不是学习模式 | 正则化、Dropout、数据增强、早停 |
| 欠拟合 | 在训练集和测试集上表现都差 | 模型过于简单，无法学习模式 | 增加模型容量、延长训练时间、更好的特征 |

```
Error
  ↑
  │ ╲  Training error          Test error  ╱
  │  ╲                                    ╱
  │   ╲─────────────────╱
  │    Underfitting ← Sweet spot → Overfitting
  └──────────────────────────→ Model complexity
```

### 4.2 关键超参数

超参数是必须在训练前手动设置的参数（模型无法学习）：

| 超参数 | 作用 | 常见范围 | 调整建议 |
|--------|------|---------|---------|
| 学习率 | 每次更新的步长 | 1e-5 ~ 1e-1 | 最重要的超参数；通常从1e-3开始 |
| 批量大小 | 每次训练步骤的样本数量 | 16 ~ 512 | 更大的批量更稳定，但需要更多显存 |
| 训练轮数 | 通过整个数据集的次数 | 10 ~ 100 | 配合早停使用；当验证集性能不再提高时停止 |
| 优化器 | 梯度更新策略 | Adam, SGD | 默认选择Adam；微调时可用SGD+动量 |

### 4.3 正则化技术

防止过拟合的常用方法：

| 技术 | 原理 | 使用方式 |
|------|------|---------|
| Dropout | 在训练过程中随机停用部分神经元 | 通常 p=0.1~0.5 |
| 权重衰减 | 在损失函数中增加权重大小的惩罚项 | L2正则化，λ=1e-4 |
| 数据增强 | 对训练数据施加随机变换（翻转、裁剪、旋转） | 图像任务中必不可少 |
| 早停 | 当验证集损失不再下降时停止训练 | patience=5~10 |
| 批量归一化 | 对每层的输入分布进行归一化 | 加快收敛，对正则化有轻微效果 |

::: tip 训练经验法则
1. 首先在小数据集上运行整个流程，以确认代码没有错误
2. 优先微调现有的预训练模型，而不是从零训练
3. 学习率是最值得调节的超参数
4. 如果训练损失没有下降，先检查数据和代码，再怀疑模型
:::

## 5. 发展历史与前沿

神经网络的发展经历了若干次“寒冬”和“复兴”，每次突破都由关键技术创新驱动。

| 时代 | 里程碑 | 关键突破 |
|------|--------|---------|
| 1958 | 感知机 | 第一个神经网络模型；只能处理线性问题 |
| 1986 | 反向传播算法 | 使多层网络的训练成为可能 |
| 1998 | LeNet（CNN） | 卷积网络在手写数字识别上取得巨大成功 |
| 2012 | AlexNet | 深度CNN在ImageNet上击败传统方法；深度学习爆发 |
| 2014 | GAN（生成对抗网络） | 两个网络对抗训练，可以生成逼真图像 |
| 2017 | Transformer | “Attention Is All You Need”；注意力机制取代RNN |
| 2018 | BERT | 预训练+微调范式；推动NLP全领域突破 |
| 2020 | GPT-3 | 1750亿参数，展示大模型的涌现能力 |
| 2022 | ChatGPT | RLHF对齐技术；人工智能进入公众视野 |
| 2023 | 多模态大模型 | GPT-4V、Claude等；可同时理解文本和图像 |

### 当前趋势

|方向 |描述 |
|------|------|
|大型语言模型（LLM）|参数数量从数亿到数万亿不等;推理、编码等领域的涌现能力 |
|多模态 |一个单一模型处理文本、图像、音频和视频 |
|高效微调 |像LoRA和QLoRA这样的技术使普通开发者能够对大型模型进行微调 |
|人工智能代理 |使大型模型能够使用工具、规划任务并自主完成复杂目标 |
|小模型提炼 |利用大型模型的知识训练更小的模型以部署到设备上 |

::: 给开发者的建议
你不需要从零开始训练神经网络。现代人工智能开发更多是**调用API**（比如OpenAI或Claude API）或**微调预训练模型**（例如使用Hugging Face）。但理解背后的原理能帮助你更明智地选择模型，设计更好的提示，更有效地诊断问题。
:::

## 摘要

|核心概念 |一句话总结 |
|---------|-----------|
|神经元 |加权和激活函数;网络中最小的计算单元|
|前向传播 |数据从输入层流向输出层，产生预测 |
|反向传播 |从损失开始，逐层计算梯度并更新权重 |
|卷积神经网络 |卷积核提取局部特征;图像处理的首选方法 |
|RNN/LSTM |循环连接维护内存;用于处理顺序数据 |
|变换器 |并行处理的自我关注;大型模型的基础架构 |
|过拟合 |模型“记忆答案”;通过正则化、脱落等方法防止 |
|迁移学习 |站在巨人的肩膀上;为新任务微调预训练模型 |
