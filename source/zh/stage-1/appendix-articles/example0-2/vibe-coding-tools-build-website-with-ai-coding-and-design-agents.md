# 使用设计与编码代理设计网站

## 本章简介

本章展示了 AI 如何连接设计与开发。我们将引导一个**设计代理**创建徽标、配色方案和页面布局，然后让一个**编码代理**将设计转换为可运行的网站。最终结果是一个从初始想法到运行页面的可复用工作流程。

---

# 1. 入门

## 1. 教程简介

我们将使用 AI 设计代理和编码代理从零构建完整网站。

- **设计代理：** 创建徽标、页面布局、配色方案及其他视觉元素。
- **编码代理：** 根据提示中提供的要求和设计编写 HTML、CSS、JavaScript 等代码。

## 2. 设计代理与编码代理

- **设计代理：** 根据提示生成图像、页面样机或视觉风格。
  - MasterGo
  - Lovart
  - Figma MCP
- **编码代理：** 根据所请求的功能和布局编写可运行的代码。
  - Z.AI
  - Trae
  - Cursor
  - Lovable

# 2. 使用设计代理创建徽标

## 1. 徽标设计的关键元素

徽标对网站的第一印象有很大影响。设计代理需要清晰描述所期望的结果。

1. **品牌名称或文字**

- 徽标中必须出现的文字，例如网站标题或品牌名称。

2. **风格或氛围**

- 徽标应传达的整体感觉。
- _示例：极简、可爱、简洁、现代、复古或未来风。_

3. **配色方案**（可选）

- 徽标颜色应与网站整体基调相符。
- 指定确切的十六进制值或一般调色板，如暖色或冷色。
- _示例：**`#171721`**（黑色）和 **`#FF7130`**（橙色）。_

4. **形状或构图**

- 说明徽标是否需要特定的形状或排列方式。
- _示例：文字在圆形内、图标配文字，或以图标为主的徽标。_

5. **图标或符号**（可选）

- 描述要出现的任何图形或符号。
- _示例：书本、闪电、AI 元素或抽象几何形状。_

## 2. 编写徽标设计提示

**示例提示**

```
"Design a minimalist logo for the brand 'My First Website'.
Use black (#171721) and orange (#FF7130), and place the text inside a circle."
```

```
"Design a logo for the brand 'AIID'.
Use a futuristic, clean, and simple style with blue and white as the main colors.
Combine an abstract symbol of AI with the text, and export a transparent PNG."
```

## 3. 向代理请求设计

- 输入上述提示，并比较代理提供的几份草稿。

# 3. 规划网站结构

## 1. 了解基本部分

在建立网站之前，先决定它需要哪些菜单项或部分。网站结构取决于访客应看到的内容以及他们应执行的操作。大多数网站通常从 **首页、关于和联系** 等部分开始。

## 2. 先绘制结构图（可选）

根据网站的目的编写一个简单的菜单结构。

### 基本菜单

1. **首页**
   1. 访客看到的第一页。
   2. 通常包含徽标、主视觉区域，以及简短的陈述或介绍。
2. **关于**
   1. 说明我们是谁或项目/服务的目的。
   2. 作品集：简短介绍和履历。
   3. 服务网站：愿景、目标及主要功能。
3. **联系**
   1. 邮箱、电话号码、社交链接或其他联系方式。
   2. 也可以包含一个简单的联系表单。

### 可选菜单

4. **服务 / 项目**
   1. 展示服务、项目或作品集作品。
   2. 通常以列表或卡片形式显示。

5. **图库**
   1. 展示图片、照片或设计作品。

6. **博客 / 新闻**
   1. 发布文章、更新或日志。

7. **常见问题 (FAQ)**
   1. 收集访客的常见问题及答案。

## 3. 选择配色方案（可选）

如果徽标已经存在，或者网站应使用特定调色板，可在提示中包含所需的颜色代码。

# 5. 使用编码代理构建网站

## 1. 了解 HTML、CSS 和 JavaScript 的基础知识

一个网站由三种主要语言构建：

- **HTML（超文本标记语言）** → 结构
- **CSS（层叠样式表）** → 外观
- **JavaScript（JS）** → 行为

它们共同组成我们使用的网页。

1. **🏗️ HTML（结构）**

- 定义页面上显示的内容。
- 放置文本、图片、按钮、链接及其他元素。
- 像建筑物的墙壁和框架一样起作用。

**示例**

```html
<h1>Hello!</h1>
<p>This is my first website.</p>
<a href="contact.html">Contact</a>
```

2. **🎨 CSS（外观）**

- 定义内容的显示方式。
- 控制文本的大小、颜色、间距、背景和按钮形状。
- 给 HTML 提供视觉上的外观和样式。

**示例**

```css
h1 {
  color: #FF7130;   /* Text color */
  font-size: 36px;  /* Font size */
  text-align: center; /* Center alignment */
}

body {
  background-color: #171721; /* Background color */
  color: white; /* Default text color */
}
```

3. **⚙️ JavaScript（行为）**

- 让页面对用户作出响应。
- 支持按钮点击、菜单、轮播图、表单提交及其他交互。
- 如果 HTML 和 CSS 提供了页面的主体和外观，JavaScript 就是让页面运作的大脑。

**示例**

```javascript
function showAlert() {
  alert("The button has been clicked!");
}
```

```html
<button onclick="showAlert()">Click me</button>
```
