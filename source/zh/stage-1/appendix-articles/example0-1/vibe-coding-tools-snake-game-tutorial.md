## 1.什么是Vibe编码？

Vibe 编码是一种利用人工智能加速应用构建的软件开发方法。它并不取代传统编程。相反，它使编程更具对话式感。人工智能研究者 Andrej Karpathy 提出了一个工作流术语，指的是开发者引导 AI 代理生成、改进和调试应用程序，而不是每行手动写。

核心转变是从**代码优先**到**意图优先**。我们不再从第一行代码开始，而是用自然语言描述预期结果。

典型的Vibe编码工作流程是一个迭代循环：

- **描述目标：** 在一句话或段落中解释期望的功能，例如“构建一个简单的蛇类游戏，后端是Python，能生成诗歌。”
- **让AI生成代码：** AI代理解释请求并创建初始结构、前端和后端逻辑。
- **运行并观察：** 运行生成的代码，检查其是否符合预期，并识别错误或遗漏。
- **提供反馈并迭代：** 继续执行诸如“蛇移动太慢;让它更快”或“`.env`@ 中的 API 密钥未正确加载;修复后端。”
- **重复：** 继续描述→生成→运行反馈循环→直到应用达到期望状态。

### Vibe 编码的主要优势

- **降低门槛：** 设计师、创始人、学生以及其他几乎没有编程经验的人也可以通过自然语言参与。
- **快速原型：** 从一个想法到最小可行产品（MVP）的时间大大缩短。
- **更高效率：** AI 处理重复的模板内容，使开发者能够专注于架构和问题抽象。
- **轻松实验：** 快速生成内容然后进行改进，使新想法和新功能更易测试。

## 2. 什么是基于 Web 的 Vibe 编程平台？

本次对比的工具分为两类：**基于 Web 的平台**和**IDE（本地开发环境）**。

两者都使用 AI 编写代码，但用户体验和适用场景存在显著差异。

### 基于 Web 的 Vibe 编程平台

**示例：** Lovable、Replit、Z.ai 和 v0

它们就像配备家具的服务式公寓：开门即可入住。

- **无需环境设置：** 无需管理 Python 环境、Node.js 版本或安装依赖项，只需打开浏览器即可开始。
- **即时预览和部署：** 平台通常在生成代码旁展示运行结果，并可一键发布可分享链接。
- **适用场景：**
  - **快速验证 MVP：** 在半小时内测试一个想法是否可行。
  - **初学者学习：** 在不先处理环境错误的情况下体验 AI 编码。
  - **轻量级应用：** 简单的网页工具、游戏和作品展示页面。

### AI 集成开发环境（本地开发环境）

**示例：** Cursor、Trae，以及带 AI 扩展的 VS Code

它们更像拥有一套完全翻新的房子。

- **强大的本地能力：** IDE 在计算机上运行，可直接访问本地文件并使用本地资源。
- **专业工作流：** 适合大型项目，支持扩展，连接本地数据库，并能进行复杂调试。
- **适用场景：**
  - **专业项目：** 长期商业项目，结构复杂。
  - **深度定制：** 对代码进行详细控制，并与 Git、Docker 及其他本地工作流集成。
  - **数据隐私：** 代码保留在本地，更符合某些企业的安全要求。

总之，**Web 平台**是初学者和小型实验的极佳起点，而**本地 IDE**则为有经验的开发者和不断扩展的项目提供更高的上限。

## 3. 什么是 AI 代理？

### AI 代理是什么？

AI 代理是一种可以感知环境、做出决策并自主执行目标的软件系统。与遵循固定指令序列的传统软件不同，代理可以适应其行为。

AI 代理区别于传统程序的几个特征：

- **自主性：** 传统程序通常等待每个用户触发，而代理可以根据目标选择下一步行动。
- **感知与记忆：** 代理从 API 响应、传感器或用户输入中收集信息，并保留上下文以便后续操作。
- **理性与目标导向：** 它围绕目标进行分析和规划，选择能够改善目标结果的行动。
- **工具使用：** 现代代理可以浏览网页、运行代码、查询数据库、发送邮件并调用其他工具，而不仅仅生成文本。

一个类比能更清楚地说明差异：

- **传统程序**就像计算器：只有在接收到精确数字和运算符后才执行操作。
- **AI 助手**就像人类助理，会搜索附近的餐厅并提供选项，同时将每个决策留给我们。
- **AI 代理**更像是一个自动化研究团队。给定一个高级目标，例如“计划一次日本旅行”，它可以分工、在线调研、调用订票 API，并在对每个步骤的监督很少的情况下组织行程。

# 2. 编写提示

## 1. 一个大提示还是几个小步骤？

一次性在一个提示中描述整个全栈应用可能很诱人。当前的工具可能生成一个令人印象深刻的初步结果，但将工作分成较小阶段通常可以提高可靠性，并使项目更容易修改。

> **提示：** 将一个大目标转化为可执行的待办事项清单，而不是期望一次完成完美结果。
> 不仅仅说“帮我做一个贪吃蛇游戏”，可以要求：
> “1. 先构建贪吃蛇前端”，
> “2. 添加一个存储分数的后端”，
> “3. 连接前端和后端”。
> 较小的步骤有助于 AI 理解需求并生成更可靠的输出。

## 2. 越清晰越好

- 在 氛围编程 中，提示与代码同样重要。清晰和具体的请求更可能产生预期结果。
- 及早说明目标和约束，这可以减少重复修改并节省时间和使用配额。

   > - 提供一个按钮，将选定词语发送到后台生成诗歌。
   > - 删除或减少生成诗歌中使用的词汇。
   >
   > * 添加游戏与创作诗歌之间的简单导航。
   > * 保持两页的集合词语可见且同步。
   >
   > 2.后端
   >
   > - 提供一个端点，接收收集的词汇并返回一首诗。
   > - 使用 DeepSeek API 生成诗歌。
   > - 将API密钥存储在`.env`，忽略该文件在`.gitignore`。

2. 输入一个 DeepSeek API 密钥，该密钥可从 [https://platform.deepseek.com/]（https://platform.deepseek.com/） 获取。
   1. LLM API密钥允许项目调用模型。该密钥敏感，必须单独存储。
      **为什么要用`.env`？为什么不应该上传到GitHub？**
   - `.env` 存储**秘密和密码**，如DeepSeek API密钥。
   - 如果它上传到 GitHub，其他人可能会看到并滥用该密钥。
   - 将 `.env` 添加到 `.gitignore`，使 Git 不会追踪该信息。
   - 项目仍可在本地使用密钥，而不会通过仓库泄露密钥。

4. 如果页面设计不满意，请在Figma或MasterGo中重新设计，并给代理修改后的设计方向。

# 5.比较AI代理平台

每个Vibe编程平台都有其独特的优势和工作流程。我们在多个平台上测试了同样的“Snake游戏搭配DeepSeek API”的要求，并从初学者角度进行了评估。

## 1.评估标准

1. **目标**
   构建一个连接到DeepSeek API的Snake网页应用。
2. **游戏详情**
   1. 游戏通过DeepSeek大型语言模型API生成诗歌。
   2. 蛇收集英语单词。盘点在回合间持续存在，重复单词有不同的计数。
   3. 生成诗歌中使用的词语从清单中移除。

3. **必备**
   1. 一个可运行的前端，支持键盘控制和Canvas渲染。
   2. 黑板上的文字和收集后更新的侧边栏。
   3. 持续的弹匣库存。
   4. 后端调用 DeepSeek，或在无密钥时返回模拟诗歌。
   5. 生成诗歌按钮，显示结果并更新库存。
   6. `.env` 支持和 `.gitignore` 保护 API 密钥。

4. **可有可无**
   1. 让用户选择包含哪些词。
   2. 提供清晰的清单和设计良好的诗歌区。
   3. 添加适合初学者的评论，解释重要逻辑。

## 3. 平台总结

| **平台**                                      | **评价**                                                                                       | **类型**  | **备注**                                                                 |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- | --------- | ------------------------------------------------------------------------ |
| **[Lovable](https://lovable.dev/)**         | 对 AI 编码初学者非常友好，是一个出色的入门选择。                                              | 网络平台  | 自动连接 Supabase 等服务。                                               |
| **[Cursor](https://cursor.com/cn/agents)**  | 对有经验的开发者来说能够显著提高生产力和代码质量。                                              | PC       | 需要编程基础和对本地依赖的理解。                                         |
| **[Z.ai](https://chat.z.ai/)**              | 更适合想检查原始 AI 生成代码的用户。                                                          | 网络平台  | 无预览；文件和服务必须手动创建和运行。                                   |
| **[Replit](https://replit.com/~)**          | 推荐用于快速将想法变成可访问的在线服务。                                                      | 网络平台  | 集成了编码、部署、协作和可视化编辑功能。                                 |
| **[Minimax](https://agent.minimaxi.com/)**  | 对观察 AI 诊断和修复错误很有用，但速度较慢且消耗代币较多。                                     | 网络平台  | 在较长工作流中重复运行测试和修复。                                       |
| **[Trae](https://www.trae.ai/)**           | 对经验丰富的用户来说，是一个高效的桌面 IDE 与 AI 智能体 组合。                                 | PC       | 需要本地安装，但适合长期项目。                                           |
| **[v0](https://v0.app/)**                   | 针对想快速获得精美 React UI 的非开发者进行了优化。                                              | 网络平台  | 专注于 UI，需要使用其他平台来完成完整的后端。
